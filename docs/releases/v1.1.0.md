# hy-text v1.1.0

`v1.1.0` adds the approved `HY-GRM-009` capitalization rule for modern Eastern Armenian in the Republic of Armenia reformed orthography.

In text written entirely in uppercase, U+0587 `և` is expanded to the two capital letters `ԵՎ`. The traditional form `ԵՒ` remains outside the supported orthography. Ordinary and mixed-case text keeps `և`, and protected quotations, code, identifiers, and official protected spellings remain unchanged.

The evidence record `SRC-UNICODE-ECH-YIWN` narrowly documents Unicode Technical Committee expert feedback distinguishing `ԵՎ` in Eastern Armenia from `ԵՒ` in Western Armenian and Iranian Eastern Armenian. `HY-GRM-009` remains explicitly classified as an editorial decision rather than claiming that the Unicode document is an official Republic of Armenia orthography decree.

## Release evidence

- The repository contract contains a dedicated failing-then-passing test for `HY-GRM-009`, including the erroneous all-caps form, the `ԵՎ` correction, an ordinary-case counterexample, protected-content scope, severity, and source basis.
- The full local suite contains 166 tests.
- `python tools/validate.py` checks stable IDs, required fields, source synchronization, Unicode NFC, release manifests, and internal corpus consistency.
- `python tools/smoke_install.py` performs six hermetic packaging checks for Agent Skills, Claude, Codex, Cursor, Gemini, and OpenClaw without writing to a real user profile.
- The immutable `v1.0.0` scoring and proofreading calibration artifacts remain published under `tests/calibration/v1.0.0`; this release changes one capitalization recommendation and does not change scoring weights, thresholds, protected-span behavior, or the five scoring dimensions.
