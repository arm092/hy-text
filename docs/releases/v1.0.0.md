# hy-text v1.0.0

`v1.0.0` is the first stable release of the source-backed text-quality corpus for modern Eastern Armenian in the Republic of Armenia reformed orthography. Western Armenian and traditional orthography remain unsupported.

The three public skills are `hy-text` for safe typography, `hy-check` for read-only proofreading, and `hy-score` for diagnostic scoring. They preserve protected code, commands, URLs, foreign-language spans, third-party quotations, and official protected spellings. The skills make no network requests, and the installation smoke check never writes to a real user profile.
