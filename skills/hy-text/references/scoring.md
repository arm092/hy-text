# hy-score – գնահատման սանդղակ (0–10)

Գնահատել միայն ժամանակակից արևելահայերեն հատվածները։ Պաշտպանված կոդը, URL-ները, հրամանները, օտարալեզու հատվածները և ուրիշի մեջբերումները չեն նվազեցնում հայերեն գնահատականը։

## Չափումներ և կշիռներ

| Չափում | Կշիռ | Աղբյուր |
|---|---:|---|
| Տպագրություն | 0.15 | `typography.md` |
| Լեզվի մաքրություն | 0.25 | `info-style.md`, `anti-patterns.md` |
| Գրագիտություն | 0.20 | `editorial-punctuation.md`, `editorial-grammar.md` |
| Կառուցվածք | 0.20 | `info-style.md`, `addenda.md` |
| Ընթերցողի համար ճշգրտություն | 0.20 | ոլորտային տեղեկատու |

Յուրաքանչյուր չափումը գնահատել առանձին 0.0–10.0 սանդղակով։ Յուրաքանչյուր նվազեցման համար մեջբերել մեկից երեք հատված և նշել `HY-*` կանոնի ID-ն։

## Խարիսխներ

| Միավոր | Նկարագրություն |
|---:|---|
| 9–10 | Հրապարակման պատրաստ, միայն հազվադեպ փոքր դիտարկումներ։ |
| 7–8.9 | Լավ աշխատանքային տեքստ, մի քանի տեղային շտկում։ |
| 5–6.9 | Ընթեռնելի, բայց համակարգային խմբագրման կարիք ունի։ |
| 3–4.9 | Լուրջ և կրկնվող խնդիրներ կան։ |
| 0–2.9 | Չափման պահանջները գրեթե չեն պահպանվել։ |

## Բանաձև

`S = round1(T × 0.15 + M × 0.25 + G × 0.20 + K × 0.20 + J × 0.20)`

որտեղ `T` = Տպագրություն, `M` = Լեզվի մաքրություն, `G` = Գրագիտություն, `K` = Կառուցվածք, `J` = Ընթերցողի համար ճշգրտություն։

## Չփոխհատուցվող սահմանափակումներ

- Որևէ չափում `< 3.0` լինելու դեպքում ընդհանուր միավորը չի կարող գերազանցել 5.0-ը։
- Տպագրությունը `< 4.0` լինելու դեպքում ընդհանուր միավորը չի կարող գերազանցել 7.0-ը։
- Գրագիտությունը `< 4.0` լինելու դեպքում ընդհանուր միավորը չի կարող գերազանցել 7.0-ը։
- Միաժամանակ մի քանի սահմանափակման դեպքում կիրառել ամենացածր առավելագույնը։

## Մակարդակներ

| Միավոր | Մակարդակ |
|---:|---|
| 9.0–10.0 | Գերազանց |
| 7.0–8.9 | Լավ |
| 5.0–6.9 | Միջին |
| 3.0–4.9 | Թույլ |
| 0.0–2.9 | Կրիտիկական |

50 բառից կարճ տեքստի դեպքում նախազգուշացնել, որ գնահատականը պակաս հուսալի է։

```markdown
|---|---:|---|

| Լեզվի մաքրություն | X.X | … |
| Գրագիտություն | X.X | … |
| Կառուցվածք | X.X | … |

### Ինչ չի չափում գնահատականը
Փաստական ճշտությունը, լսարանին համապատասխան տոնը, հեղինակային ինքնատիպությունը, արդյունավետությունը և բրիֆի կատարումը։
```
