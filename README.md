# hy-text

`hy-text`-ը ժամանակակից արևելահայերենի տեքստերի որակի բաց և աղբյուրահեն տեղեկատու է արհեստական բանականության գործակալների համար։ Այն նախատեսված է խմբագիրների և բովանդակային թիմերի համար։

> [!WARNING]
> Նախագիծը մշակման փուլում է։ Մինչև բոլոր ստուգումների և ձեռքով խմբագրական վերանայման ավարտը կայուն թողարկում չկա։

## Սահմաններ

- Աջակցվում են միայն Հայաստանի Հանրապետությունում գործածվող ժամանակակից արևելահայերենը և բարեփոխված ուղղագրությունը։
- Արևմտահայերենը և ավանդական ուղղագրությունը չեն աջակցվում։
- Կոդը, URL-ները, հրամանները, օտարալեզու հատվածները և ուրիշի մեջբերումները չեն վերաշարադրվում։

## Հմտություններ

- `hy-text` – անվտանգ տպագրություն գործակալի հայերեն պատասխանում։
- `hy-check` – ամբողջական, միայն կարդալու ռեժիմով սրբագրում։
- `hy-score` – որակի գնահատում 0–10 սանդղակով։
